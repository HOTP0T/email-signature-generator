    Good to know
    
    
    
      
    
        
    My logo doesn't show in Gmail
    
        
    An uploaded image is never put online: the page shrinks it and embeds it in the signature's HTML, so it has no link. Apple Mail and Outlook send it with each email; Gmail removes it. Put the image online (your website, a CDN, a public GitHub file) and paste its link under Image link, at least twice the width you display.
    
      
    
      
    
        
    Where do the icons come from?
    
        
    Mail apps can't draw icons, so each one is a small PNG hosted with this page, in the grey closest to your Details colour. If a mail app blocks images until the reader allows them, a word such as "Phone" shows instead. Untick the icons option to leave them out.
    
      
    
      
    
        
    Rounded corners look square
    
        
    Classic Outlook for Windows ignores rounded corners and draws them square. Every other common app shows them.
    
      
    
      
    
        
    Colours change in dark mode
    
        
    Some mail apps recolour text when the reader uses dark mode. Mid-tone accents and a logo with its own background hold up best.
    
      
    
      
    
        
    Where are my details kept?
    
        
    Only in this browser's storage, uploaded image included, so the page remembers them next time. Nothing is sent anywhere. A brand link carries your brand settings in the link itself, never your personal details.
    
      
    
      
    
        
    Can I host my own copy?
    
        
    Yes. The page is open source (MIT): fork it on GitHub and publish it with GitHub Pages, and signatures made there load their icons from your own site.
